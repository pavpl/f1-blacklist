# Флаги пилотов

SVG-файлы взяты из проекта [flag-icons](https://github.com/lipis/flag-icons) версии 7.3.2,
формат 4x3. Лицензия MIT, полный текст — в `LICENSE`.

Используются только флаги национальностей пилотов из `data.js`. При добавлении нового пилота
положите сюда соответствующий SVG с ISO 3166-1 alpha-2 кодом в имени файла и добавьте код
в `FLAGS` или `DRIVER_META`.

Флаги Испании и Мексики заменены упрощёнными локальными версиями без герба: на размере иконки
герб всё равно не читается, а исходные SVG весили около 80 КБ каждый.
