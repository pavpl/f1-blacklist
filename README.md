# F1 Blacklist — калькулятор шансов на титул

Простое одностраничное приложение (HTML / CSS / JS) в стилистике «Blacklist» из *Need for Speed: Most Wanted*: календарь **Формулы-1 2026** на **23 этапа**, **23 пилота**, учёт спринт-уикендов при расчёте максимума очков.

## Возможности

- **Автоматическая загрузка данных:** При загрузке страницы приложение запрашивает актуальное положение в чемпионате и пройденные этапы через Jolpi API.
- Вывод списка гонщиков, **сортировка по убыванию** очков. Рядом с текущими очками отображается максимально возможный балл, который гонщик может набрать до конца сезона.
- **Математика:** остаётся ли шанс на титул (сравнение с лидером и суммой максимумов на оставшихся этапах).
- **Индекс %:** насколько максимально возможный итог пилота (если на каждом оставшемся ГП он берёт максимум по модели) близок к такому же «потолку» у лидера. Очки за лучший круг **не** учитываются.
- Приветственное окно с подробной информацией о проекте.

## Запуск

Откройте [`index.html`](index.html) в браузере (двойной клик) или разверните на GitHub Pages. Для автоматической работы с API необходимо подключение к интернету.
